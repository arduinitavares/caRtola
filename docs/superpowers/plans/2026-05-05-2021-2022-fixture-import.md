# 2021/2022 Fixture Import Execution Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to run this operational plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add validated official fixture files for 2021 and 2022 so matchup feature experiments can run across 2021-2025.

**Architecture:** Use the existing TheSportsDB fixture importer and its Cartola played-club validation. Patch only team-name aliases in `data/01_raw/fixtures/club_mapping.csv` if the importer reports unmapped teams, then audit fixture coverage before rerunning model experiments.

**Tech Stack:** Python 3.13, uv, existing `scripts/import_fixture_schedule.py`, existing `scripts/audit_matchup_fixture_coverage.py`.
